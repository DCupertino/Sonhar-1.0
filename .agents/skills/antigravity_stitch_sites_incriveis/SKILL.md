# Antigravity + Stitch: Criando Sites Incríveis

Esta habilidade orienta a integração entre as capacidades de design do **Google Stitch** (acessadas via MCP) e o poder de implementação do **Antigravity** para criar interfaces premium, responsivas e visualmente deslumbrantes.

## Como Usar o Stitch MCP com o Antigravity

Quando esta habilidade estiver ativa, siga as diretrizes abaixo para criar e refinar websites:

### 1. Extração do Design DNA e Recursos
* **Obtenção do Design DNA**: Utilize as ferramentas do servidor MCP `stitch` para inspecionar os projetos do usuário. Busque as paletas de cores (cores primárias, secundárias, gradientes), tipografia de fontes do Google Fonts, padrões de espaçamento e o estilo visual geral (glassmorphism, flat moderno, neumorphism, etc.).
* **Busca de Assets**: Obtenha os códigos HTML/CSS gerados ou os metadados dos componentes diretamente dos projetos do Stitch para servir de fundação na implementação.

### 2. Implementação com Rich Aesthetics (Estética Premium)
Ao transformar os designs do Stitch em código no Antigravity:
* **Fidelidade Visual**: Traduza com precisão as cores, gradientes e estilos do Stitch para CSS nativo (Vanilla CSS).
* **Tipografia Moderna**: Importe as fontes corretas do Google Fonts no início do seu arquivo de estilo (ex: `index.css`).
* **Micro-animações**: Adicione transições suaves (`transition: all 0.3s ease`) em botões, links, cards e menus interativos.
* **Componentização**: Organize o HTML5 de forma semântica e os estilos de forma modular e reutilizável.

### 3. Workflow de Desenvolvimento e Alinhamento
* Quando o usuário solicitar uma nova tela ou modificação, tente alinhar com o design existente extraído do Stitch para manter a consistência visual de ponta a ponta.
* Se necessário, gere novas imagens conceituais ou assets de apoio usando a ferramenta `generate_image` para complementar o layout antes de finalizar o código.
